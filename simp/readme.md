簡介
本作致敬九十年代風行的 DOS 打字教學程式，以單一 HTML 檔離線運作，簡倉版本針對簡體字與繁簡通用字全面重構：內建字庫按簡體字形重新拆碼（如「见＝月中山」而非繁體「見」之 BUHU），盡量根除「簡體字套用繁體碼」之誤。隨著淘寶、拼多多、微信等平台與跨境交流日漸普及，以倉頡輸入簡體字的需求大增，本作正是為此而生。
功能
• 打字練習：一級／二級／三級字範圍任選，附「繁簡通用字」開關；打滿二十字自動結算速度與準確率。
• 實力測驗：五分鐘計時，內建詞庫及題庫。亦可外掛。
• 倉頡查碼：支援繁簡輸入反查字根與拆碼。
• 最佳成績排行榜：本機保存歷史紀錄，追蹤進度。
• 倉頡入門：26 頁分頁教材（引言＋廿四字根＋總結），每頁附標準拆碼示例與粵語口訣詩，口訣用字經嚴格篩選，以求字字精準、消除拆碼歧義。
• 觸屏支援：內建虛擬鍵盤，ABC／中文字根雙佈局，字根鍵完全依照 QWERTY 鍵位排列，可橫掃切換、置左置右；偵測到實體鍵盤後虛擬鍵盤自動隱藏，再點螢幕即喚回，實體與虛擬可隨時交替使用。
• 介面切換：主選單設「繁轉簡」按鈕，一鍵切換繁簡介面，各畫面文字即時轉換。
使用方式
• 電腦：直接以瀏覽器開啟 github.io網址，或已下載的html檔。
• Android：以 Chrome 或內建瀏覽器開啟即可。
• iOS：從 WhatsApp／郵件／檔案 App 直接點開會進入系統預覽器，JavaScript 被停用而無法操作，此屬 iOS 安全限制。請改以 Safari 開啟部署網址，或將檔案下載至電腦開啟。
計分說明
測驗中使用 Z 萬用鍵時不會自動首選，須以 1–9 手動選字，貼近真實輸入法行為，防止 Space 保送拿分；不含 Z 的正常輸入仍自動首選，速度體驗不變。重碼字以「1–9」數字鍵選字，即時預覽顯示當前字根組合，按「?」可隨時反查字碼。
