本作「致敬」九十年代風行之 DOS 打字教學程式。內建字庫以標準三代倉頡為主碼，部份字附有容錯碼，並只含五代部分字碼；收錄部份成語及香港用語詞彙作為命題題材。如需更完整或不同版本之字碼，可自行準備 chinese.tt 替代碼表上傳載入（每行「字 碼」，UTF-8 或 Big5 皆可）。
▶ 手機／平板開啟方式
• iOS 從 WhatsApp／Mail／檔案 App 直接點開本檔時，系統預覽器會停用 JavaScript，只見靜態畫面而無法操作——此屬 iOS 安全限制，並非程式故障，且無法於預覽內解除。
• iOS 建議做法：改用網頁版——以 Safari 開啟本程式之部署網址，即可完整執行；或將本檔下載／傳送至電腦（Mac／PC），以瀏覽器開啟使用。
• Android 以 Chrome／內建瀏覽器開啟本檔即可完整執行。
• 手機建議打橫以獲得最佳比例；進入練習或測驗時，螢幕底部會自動出現虛擬鍵盤，毋須外接實體鍵盤。
▶ 本機外掛字庫
• 方法一（零點擊）：把 chinese.tt 內容以 window.EXTERNAL_CHINESE_TT 包裝成 JS 變數，存成 chinese_dict.js 放在本檔同目錄，開啟即自動載入。
• 方法二（永久記憶）：於測驗設定選取 chinese.tt 一次，內容即存入瀏覽器（IndexedDB），之後每次開啟自動套用，毋須再選。
• 網上部署：同目錄放 chinese.tt 即自動讀取。
▶ 匯出 .js 的用途（排行榜頁）
• 排行榜頁「匯出 .js」會把目前生效的字庫（內建＋已載入之擴充碼）包裝成 chinese_dict.js 下載。
• 把此檔與本程式 HTML 放在同一資料夾，下次開啟 HTML 即自動載入，毋須再手動上傳——適合備份或分發給他人（連同 HTML 一起傳）。
• 「匯出碼表 .tt」則為純文字碼表，供上傳載入或編輯之用。
▶ 電腦命題題庫（.txt / .atc）
• 按「📂 選擇題庫資料夾」一鍵匯入整個資料夾的純文字檔（一行一詞或整段文章皆可，自動抽取字庫內漢字），選一次永久記住。
• 本機另可放 words_dict.js（window.EXTERNAL_WORDS="詞1 詞2 …"）自動載入。
• http:// 部署時自動依序偵測 words.txt、questions.txt、*.atc 等。
▶ 關於排行榜資料的儲存
• 排行榜成績只儲存在本機瀏覽器內（localStorage），不會上傳到任何伺服器，也不會同步到其他裝置或瀏覽器。
• 換裝置、換瀏覽器（或經不同方式開啟，如內建瀏覽器 vs Safari）所見的排行榜互不相通。
• 若清除瀏覽器的「網站資料／歷史記錄」，排行榜紀錄即會消失，請自行留意外。
▶ 其他
• 畫面底部之 Enter／Esc／↑↓ 按鈕等同實體鍵盤；觸控裝置偵測到實體鍵盤輸入後，虛擬鍵盤會自動隱藏。

一、倉頡字母（廿四基本字根）
類別字母鍵位
哲理類日月金木水火土ABCDEFG
筆畫類竹戈十大中一弓HIJKLMN
人體類人心手口OPQR
字形類尸廿山女田卜STUVWY
記憶口訣：日月金木水火土（A-G）、竹戈十大中一弓（H-N）、人心手口（O-R）、尸廿山女田難卜（S-Y）；X 為難字鍵、Z 為重碼/萬用鍵。
二、取碼次序：由上至下、由左至右、由外至內
• 上下形：想=DUP｜音=YTA｜安=JV｜字=JND
• 左右形：明=AB｜林=DD｜好=VND｜你=ONF
• 內外形：回=WR｜國=WGI｜因=WK
• 原則：拆字時先分「字首」與「字身」，各自獨立取碼，最後合併。
三、連體字與分體字
• 連體字（不可分割的整體字）：最多取四碼，超過時取「首、二、三、尾」四碼。
例：鳥=HAYF｜馬=SQSF｜車=JWJ｜身=HXH
• 分體字（2-3 型）：字首取二碼＋字身取三碼。
例：鯉=NFWG｜河=EMNR｜想=DUP
• 分體字（2-2-1 型）：字首二碼＋次字首二碼＋字身一碼。
例：語=YRMMR｜謝=YRHHI｜微=HOUSK
• 分體字（2-1-2 型）：字首二碼＋字身首尾各一碼。
例：菇=TVJR｜替=QOGR
• 字首超過兩碼時，只取首尾兩碼（中間省略）。
四、取碼五原則
① 精簡原則：能用較少字根完成拆解，就不用較多。王=MG（非三碼）
② 完整原則：優先保留字形輪廓完整的字根。生=HQM｜丰=QJ
③ 字型特徵原則：避免在轉角處切斷筆畫。求=IJE
④ 省略原則：超出碼數限額時，中間部分省略。麻=IDD｜點=WFYR
⑤ 複合字首：慣用的整體偏旁視為一個單位取碼。
常見複合字首：鬼=HI｜門=AN｜鬥=LN｜行=HOMN｜衣=YHV
五、例外字與難字（X 鍵）
• 部分字形無法以一般字根表達，以 X（難）鍵代表省略部分：
肅=LX｜齊=YX｜臼=HX｜兼=TXC｜淵=EXBT｜慶=IXE
• 這類「難字」數量有限，多打幾次自然記住；遇到時按「?」即可反查。
六、重碼與選字
• 不同字可能共用相同字碼（重碼），此時畫面會列出候選字；本軟體會自動把目標字排在第一位，按空白鍵即可直接上字。
• 亦可按 [1-9] 直接選字；候選多於九個時，按 [ 或 ] 翻頁。
• 真實倉頡環境中目標字未必排第一，建議同時熟習數字鍵選字。
• 測驗模式下按 [Z] 萬用鍵可代替不確定的字母，且支援任意長度（例：打「EZS」可列出 E 開頭 S 結尾的所有匹配字，如 ES、ETS、ETCS）。
七、本軟體操作要訣
• 打字練習：逐字顯示字碼方格，打錯立即變紅；打滿正確字碼後按 Space 上字；按「?」或「🔍 查碼」可查看當前字的標準碼（不影響計分）；[Tab] 跳過當前字。
• 實力測驗：按第一個字母即開始計時；Esc 一次清除當前字碼、再按退出測驗。
• 電腦命題題庫：按「📂 選擇題庫資料夾」一鍵載入整個資料夾的 .txt / .atc（選一次永久記住）；本機亦可放 words_dict.js；http:// 下自動偵測 words.txt 等。
• 倉頡查碼：輸入任何字即顯示主碼與容錯碼。
• 最佳成績排行榜：測驗結束後輸入姓名即可登錄。
八、練習方法建議
1. 先熟記廿四字母鍵位，練到不用看鍵盤。
2. 從簡單字開始（二至三碼），建立拆字直覺。
3. 每天練習十五分鐘，持之以恆比一次苦練更有效。
4. 遇到不會拆的字，用「查碼」功能弄懂後，再回到練習重打一次。
5. 熟練後挑戰「實力測驗」，以速度與準確率同時進步為目標。
